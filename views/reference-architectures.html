What is a Reference Architecture?

A Reference Architecture is a validated implementation model that maps an enterprise solution to a specific technology ecosystem.

While an Architecture Blueprint™ focuses on conceptual design principles, a Reference Architecture™ demonstrates how that design can be implemented using real-world enterprise platforms, products, and deployment patterns. Vakratron Reference Architectures™ help organizations accelerate implementation planning, standardize deployments, reduce technology risk, and establish repeatable enterprise architectures.
